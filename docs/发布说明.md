# C++ 多线程文件扫描器演示版发布说明

## 版本信息

| 项目 | 内容 |
| --- | --- |
| 演示版本 | v1.0.0-demo |
| 平台 | Windows 10/11，64 位 |
| 构建方式 | C++17 + CMake + Ninja + MSYS2 UCRT64 |
| 发布类型 | 实习项目演示版，不包含安装器 |
| 当前远程分支 | `main` |

## 发布版能力

- 递归目录扫描和有界多线程任务队列。
- 1～64 线程配置，支持位置参数、长参数、短参数和等号形式。
- 扩展名、最小大小、最大大小过滤。
- 文件路径、大小、扩展名元数据记录。
- 线程安全错误收集和 UTF-8 错误日志。
- UTF-8 CSV 导出，兼容 Excel 中文表头。
- Win32 GUI、目录选择、进度条、颜色主题和扩展名表格。
- 1/2/4/8 线程性能基准和完整 smoke test。

## 五分钟演示流程

在项目根目录打开 PowerShell：

### 1. 构建

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\.vscode\build.ps1"
```

### 2. 基础扫描

```powershell
.\build\file_scanner.exe .\src 4
```

讲解：主线程遍历目录，线程池工作线程读取文件大小，统计结果通过原子变量和互斥锁汇总。

### 3. 过滤和 CSV

```powershell
.\build\file_scanner.exe -p .\src -t 4 -e cpp -o .\output\demo.csv
```

讲解：长短参数行为一致，CSV 每个匹配文件一行，路径字段支持特殊字符转义。

### 4. 错误日志

```powershell
.\build\file_scanner.exe --path .\not-found-demo --threads 4 --log .\logs\demo-errors.log
```

讲解：非法目录返回非零退出码并写入时间、路径和原因，不会静默失败。

### 5. 性能对比

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\benchmark.ps1" -ScanPath ".\src"
```

讲解：每个线程配置重复运行，使用墙钟时间计算吞吐量，并校验不同线程数的文件数、总大小和错误数一致。

### 6. GUI

```powershell
.\build\file_scanner_gui.exe
```

讲解：GUI 与 CLI 共用扫描引擎，扫描工作在线程中执行，窗口线程负责状态、进度和结果展示。

## 一键发布检查

使用独立的 Release 构建目录，不删除现有 `build/`：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\release_check.ps1" -ScanPath ".\src"
```

检查内容包括 Release 配置、CLI/GUI 产物、CSV 演示、Release CLI smoke test 和 GUI 正常退出。生成的 `build-release-check/`、`output/` 和 `logs/` 均不进入 Git。

## 已知限制

- 当前为 Windows Win32 演示版，没有安装器和跨平台 GUI。
- GUI 当前不直接导出 CSV，需要使用 CLI 参数导出。
- 性能数据受扫描目录规模、磁盘缓存和系统负载影响，小目录不适合得出绝对结论。
- 修改时间过滤、数据库存储、网络扫描和大规模压力测试留作后续迭代。
