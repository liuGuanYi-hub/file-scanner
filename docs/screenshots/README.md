## 截图规范

- 使用 PNG 格式，优先使用 1600×900 或清晰裁剪尺寸。
- 当前命令行版本优先截图终端运行结果。
- 截图中不得出现账号、令牌、私人文件名或其他敏感信息。
- 文件名使用英文小写、数字和短横线，按功能演进顺序编号。
- 只有在功能实现、编译和运行验证通过后，才将图片加入 README。
